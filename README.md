D-TRACK is a web application designed to help users log food easily, monitor calories, and store recipes in a clean and user-friendly interface.

This is a coursework project for the ITEC3020 Web Technologies course (Final Project) that showcases full-stack development skills in HTML, CSS, JavaScript, and Node.js/Express.

Features

User Authentication – Login, register, change username/email

Calorie Logging – Log daily calorie consumption

Recipe Management – Store recipes, upload photos

Food Storage – Store food items to refer to later

Clean UI – Simple, easy navigation and accessibility-friendly

Custom Styling – Red color scheme for a clean, minimalist appearance

Project Structure

Login.html – User login page

Register.html – Registration of users

Home.html – Principal dashboard

Profile.html – Management of user profiles

Recipe.html – Recipe creation and viewing

More.html – Miscellaneous features/resources

ContactUs.html – Contact/support

style.css – Personalized CSS (red-themed design)

Frontend

HTML – Content and form (e.g., navigation, forms, inputs)

CSS – Visuals (red color scheme, simple interface)

JavaScript – User input management, interactivity, linking to local database

⚙️ Backend

Node.js – Server link, request handling

Express.js – Simplifies routing and middleware setup

Local Database – Stores recipe, food log, and user information

API – Handles data interaction and authentication

Installation & Setup

Clone the repo:

Install deps:
npm install

Start server:
node server.js

Open in browser:
http://localhost:3000
